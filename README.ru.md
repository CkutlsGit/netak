# Netak RESTful API

RESTful API для управления постами и пользователями с аутентификацией на основе JWT.

## 📋 Обзор

Netak - это приложение на Spring Boot, простая платформа для создания и просмотра постов. Проект использует безопасную аутентификацию с использованием JWT-токенов и ограничение доступа на основе ролей.

## 🚀 Стек

### Backend
- **Java 21** - основной язык
- **Spring Boot 4** - фреймворк приложения
- **Spring Data JPA** - доступ к базе данных и ORM
- **Spring Security** - аутентификация и авторизация
- **JWT** - аутентификация на основе токенов

### База данных
- **PostgreSQL** - продакшн база данных
- **H2** - база данных для тестирования

### DevOps
- **Docker** - контейнеризация
- **Docker Compose** - оркестрация нескольких контейнеров

## ✨ Возможности

- 🔐 **Аутентификация и авторизация**
  - Регистрация и вход пользователей
  - JWT-токены (access/refresh)
  -  Ограничение доступа на основе ролей (User/Admin)

- 👤 **Управление пользователями**
  - Просмотр пользователей (только Admin)
  - Удаление пользователей (только Admin)

- 📝 **Управление постами**
  - Создание постов (аутентифицированные пользователи)
  - Просмотр всех постов (аутентифицированные пользователи)
  - Просмотр постов пользователя (только Admin)
  - Удаление своих постов (аутентифицированные пользователи)
  - Удаление любого поста (только Admin)

- ✅ **Валидация данных**
  - Валидация запросов
  - Кастомная обработка ошибок

## 📚 API Endpoints

### Аутентификация

| Метод | Endpoint | Описание |
|--------|----------|-------------|
| POST | `/api/auth/register` | Регистрация нового пользователя |
| POST | `/api/auth/login` | Вход и получение токенов |
| POST | `/api/auth/refresh` | Обновление access-токена |

### Пользователи (только Admin)

| Метод | Endpoint | Описание |
|--------|----------|-------------|
| GET | `/api/user/{id}` | Получить пользователя по ID |
| GET | `/api/user` | Получить всех пользователей |
| DELETE | `/api/user/{id}` | Удалить пользователя по ID |

### Посты

| Метод | Endpoint | Описание |
|--------|----------|-------------|
| GET | `/api/post` | Получить все посты (аутентифицированные) |
| GET | `/api/post/{id}` | Получить пост по ID (только Admin) |
| GET | `/api/post/user/{id}` | Получить посты пользователя по ID (только Admin) |
| POST | `/api/post/create` | Создать новый пост (аутентифицированные) |
| DELETE | `/api/post/delete/{id}` | Удалить пост (аутентифицированные, только свои посты) |

### Процесс аутентификации

1. **Зарегистрируйте** нового пользователя
2. Передавайте `accessToken` в заголовке `Authorization` для защищённых endpoints:
   ```
   Authorization: Bearer <access_token>
   ```
3. Используйте `refreshToken` для получения нового `accessToken`, когда срок действия истечёт

## 🔒 Безопасность

- **JWT Authentication**: Stateless-аутентификация с access и refresh токенами
- **Role-Based Access**: роли USER и ADMIN с разными правами
- **Password Encoding**: BCrypt для безопасного хранения паролей
- **Protected Routes**: все endpoints, кроме аутентификации, защищены
- **Post Ownership**: пользователи могут удалять только свои посты (кроме Admin)

## 🔄 Примеры использования API

### Регистрация пользователя
```bash
POST /api/auth/register
{
    "email": "user@example.com",
    "username": "johndoe",
    "password": "securePassword123"
}
```

### Вход
```bash
POST /api/auth/login
{
    "email": "user@example.com",
    "password": "securePassword123"
}
```

### Создание поста
```bash
POST /api/post/create
Authorization: Bearer <access_token>
{
    "title": "My First Post",
    "description": "This is the content of my first post."
}
```

### Получить все посты
```bash
GET /api/post
Authorization: Bearer <access_token>
```

### Удалить пост
```bash
DELETE /api/post/delete/{id}
Authorization: Bearer <access_token>
```
